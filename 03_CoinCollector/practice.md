## Reskin the Game
Transform Coin Collector into a different game concept.

Reuse the same interaction and score mechanics but change the theme.

Choose one:

### Option A: Food Collector
![alt text](explainationImages/image-6.png)

- Collect apples, bananas, and other food.
- Display the number of collected items.
- Win after collecting enough food.

### Option B: Treasure Hunt
![alt text](explainationImages/image-7.png)
- Collect gems and treasures.
- Give different items different point values.
- Add a locked treasure chest.

### Option C: Quiz Maze
![alt text](explainationImages/image-8.png)
- Collect question cards.
- Display a question when a card is collected.
- Award points for correct answers.
- Display the final score.
