# 🎮 Godot Game Development Course

A beginner-friendly, hands-on course covering **2D and 3D game development using Godot 4 and GDScript**.

## 📚 Course Topics

- **Godot Foundations:** Editor, scenes, nodes, GDScript, and player input.
- **Player Movement & Physics:** Movement, jumping, collisions, and gravity.
- **Interactions & Gameplay:** Signals, collectibles, scoring, and projectiles.
- **Animations & Game States:** Character animations, health systems, and game flow.
- **UI & Level Design:** Menus, HUDs, levels, and scene navigation.
- **2D & 3D Game Development:** Core concepts, mechanics, and workflows for both dimensions.
- **Advanced Mechanics:** Enemy AI, audio, playtesting, and game prototyping.

## 🛠️ Tools

- Godot 4
- GDScript

## 🎯 Final Goal

Build playable game prototypes while learning the fundamentals of game design, programming, and development through practical exercises and projects.

## 👥 Who Is This For?

Beginners, students, and aspiring game developers. No prior Godot experience is required.

**Learn by building. Experiment by creating. Bring your game ideas to life.**
